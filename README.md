# Java Constructor Programs

This repository contains Java programs demonstrating **Constructors** in Object-Oriented Programming (OOP).

These programs were created to practice and understand how constructors are used to initialize objects in Java.

## 📚 Concepts Covered

* Constructors in Java
* Default Constructor
* No-Argument Constructor
* Parameterized Constructor
* Constructor Overloading
* Copy Constructor
* Object Initialization
* Use of `this` keyword in Constructors

## 🛠️ Technologies Used

* **Programming Language:** Java
* **IDE:** Eclipse IDE
* **Concept:** Object-Oriented Programming

## 🚀 How to Run

1. Clone or download this repository.
2. Open the Java source files in Eclipse IDE or another Java IDE.
3. Open the desired Java class.
4. Run the program as a Java Application.

## 🎯 Purpose

This repository was created for Java programming practice and to strengthen my understanding of **Constructors and Object Initialization** in Java.
